# Hello, iOS

A small SwiftUI app for working through Phase 0 of the iOS development
roadmap. The screen includes an SF Symbol, a greeting, and a button that
animates between two states.

## Run the app

1. Open `HelloIOS.xcodeproj` in Xcode 16 or later.
2. Select an iPhone simulator from the run destinations.
3. Press **Run** (`Command-R`).
4. Tap **Say hello** and confirm that the greeting and symbol change.
5. Repeat with a second simulator size before checking off the roadmap item.

The target uses automatic signing and the placeholder bundle identifier
`com.example.HelloIOS`. Choose your development team and replace the bundle
identifier before running on a physical device.
